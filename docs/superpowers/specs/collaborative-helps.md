# Collaborative Ideation App — Concept

> **Scope note:** this is a spec for a distinct product (a facilitated team-ideation app). It is
> not an input to the `team-assess` rubric.

The goal of this project is to create an app that facilitates solving process and product ideation
through a team of participants. The app must gather project information, team inputs as written
notes and audio input converted into transcripts, and facilitate collaboration by:

1. assimilating team inputs,
2. asking for clarification of participant inputs by restating what was written and said,
3. asking team members for input by name based on their description of what they do, their
   expertise and knowledge — gathering their input and storing this as additional information in
   docs or a database to use as a reference throughout the team interactions.

The higher level goal is to use this app to clarify and iterate thinking, challenge assumptions by
asking relevant questions, and connect data and team members together by gathering iterative
feedback through this collaboration process. Create a simple and easy to understand app design
document and UI that will facilitate these team collaborations, audio and data collection, and a
conversational chat bot that synthesizes this information into conversational format for the
collaboration team.
